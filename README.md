# Array Lab Assignments

This repository contains C++ programs based on Array and Matrix Operations.

## Programs Included

### 1. Menu Driven Array
- Create
- Display
- Insert
- Delete
- Linear Search

### 2. Remove Duplicate Elements
- Removes duplicate elements from an array.
- Keeps only unique elements.

### 3. Array Rotation
- Left rotation by K positions
- Right rotation by K positions

### 4. Array and Matrix Operations
- Reverse an array
- Matrix multiplication
- Transpose of a matrix

### 5. Row and Column Sum
- Calculates the sum of every row.
- Calculates the sum of every column.

## Technologies Used

- C++
- Arrays
- 1-D Arrays
- 2-D Arrays
- Loops
- Conditional Statements

## Files

- Ques1: Menu Driven.cpp
- Ques2: Remove Duplicates.cpp
- Ques3: Array Rotation.cpp
- Ques4(a) Reverse Array.cpp
- Ques4(b) Matrix Multiplication.cpp
- Ques4(c) Matrix Transpose.cpp
- Ques5: Row Column Sum.cpp

## Purpose
These programs are created as part of Array Lab Assignments to practice basic array and matrix operations using C++.
